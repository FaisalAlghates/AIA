# AI Automation Agency

A modular web platform for an AI automation agency, designed to showcase digital services, automation solutions, company resources, and business capabilities.

## Overview

The AI Automation Agency platform provides a professional web presence for presenting AI, automation, software, and digital solutions. It includes public-facing business pages, content management features, analytics, services, portfolio, pricing, documentation, and administrative management.

## Features

* AI and automation solutions
* Services management
* Automation Hub
* Portfolio management
* Pricing plans
* Blog and resources
* Documentation
* FAQ and support pages
* Team management
* Analytics dashboard
* Admin dashboard
* User authentication
* Profile and account settings
* Modular application architecture

## Technologies

* PHP 8.2+
* Laravel 12
* Livewire
* Laravel Volt
* Tailwind CSS
* Vite
* SQLite / database support
* Nwidart Laravel Modules
* Laravel Modules Livewire

## Architecture

The application uses a modular Laravel architecture, with separate modules for major business functions such as Home, Solutions, Services, Blog, Documentation, Pricing, Analytics, Automation Hub, Portfolio, Team, Resources, Support, and Legal.

This structure makes the platform easier to maintain, expand, and customize.

## Purpose

The project demonstrates the development of a scalable business platform focused on AI automation and digital solutions, combining a professional frontend experience with structured backend management.
